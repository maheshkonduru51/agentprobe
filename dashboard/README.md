# AgentProbe Dashboard

Run from the project root with `streamlit run dashboard\app.py`.

The seven user-facing pages are:

1. Run Experiment (the `app.py` home page)
2. Leaderboard & Compare
3. Trace Viewer
4. Failure Analysis
5. Safety Report
6. Scientist-lite
7. Interpretability (optional)

The Run Experiment page also includes a custom-task tab as a small project enhancement.
